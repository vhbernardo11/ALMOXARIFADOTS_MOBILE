# RENDA EXTRA DT — Dashboard

Dashboard online do projeto RENDA EXTRA DT.

## Estrutura

- `index.html`: interface do dashboard.
- `data.json`: dados financeiros e operacionais exibidos pelo painel.

## Atualização

O fluxo recomendado é GitHub → Vercel. Alterações no `data.json` devem gerar novo deploy automaticamente quando este repositório estiver conectado ao projeto Vercel.
